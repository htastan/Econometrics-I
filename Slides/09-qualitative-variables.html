Warm-up: is this discrimination?

In wage1, the average hourly wage is $7.10 for men and $4.59 for women, a raw gap of $2.51.

What can we conclude from this comparison?

A) Nothing at all: the difference could be pure chance

B) It measures discrimination: women are paid $2.51 less for the same work

C) There is a gap, but part of it may reflect differences in education, experience and tenure. We must compare comparable workers.

The raw difference is statistically significant (t = -8.3), so (A) is wrong. But it compares all men with all women, not workers with the same characteristics: this is again a ceteris paribus question. Today we put qualitative information such as gender into the regression, so that the gap can be estimated holding education, experience and tenure fixed.

Describing qualitative information

Dummy variables: the base group, the dummy variable trap, and dummies with a log dependent variable.

Dummy (binary) variables

Many important factors are qualitative: gender, marital status, region, industry, whether a country has a certain law, …

female_i = \begin{cases} 1 & \text{if person } i \text{ is female} \\ 0 & \text{otherwise} \end{cases}

  • It does not matter which category gets the 1, but we must know the coding to interpret the results.
  • The category coded 0 is the base (reference, benchmark) group.
  • Names: dummy, binary or indicator variable.
head(wage1[, c("wage", "educ", "female", "married")], 5)
#>   wage educ female married
#> 1 3.10   11      1       0
#> 2 3.24   12      1       1
#> 3 3.00   11      0       0
#> 4 6.00    8      0       1
#> 5 5.30   12      0       1

A single dummy variable

wage = \beta_0 + \delta_0\, female + \beta_1\, educ + u

Take conditional expectations for each group (with E(u\mid \cdot) = 0):

\begin{aligned} E(wage \mid female = 1, educ) &= (\beta_0 + \delta_0) + \beta_1 educ\\ E(wage \mid female = 0, educ) &= \beta_0 + \beta_1 educ \end{aligned}

\boxed{\;\delta_0 = E(wage\mid female=1, educ) - E(wage\mid female=0, educ)\;}

\delta_0 is the difference in intercepts: the wage gap between women and men at the same level of education. The slope \beta_1 is the same for both groups, so the two lines are parallel.

Interactive: what the dummy does

Start with “one line for everybody”: the model cannot express any gap. Add the female dummy: two parallel lines, gap about -2.27 dollars at every education level. Add the interaction: the lines are almost parallel anyway, the difference in slopes is tiny and insignificant. Switch to log(wage) to read the gap in percent.

Adding quantitative variables

w1 <- lm(wage ~ female + educ + exper + tenure, data = wage1)

\begin{aligned} \widehat{wage} &= - \underset{\small (0.725)}{1.57} - \underset{\small (0.265)}{1.81}\,female + \underset{\small (0.0493)}{0.572}\,educ + \underset{\small (0.0116)}{0.0254}\,exper \\ & + \underset{\small (0.0212)}{0.141}\,tenure \\ & n = 526,\quad R^2 = 0.364 \end{aligned}

  • On average, women earn $1.81 less per hour than men with the same education, experience and tenure. The raw gap was $2.51, so part of it was due to differences in those characteristics.
  • Testing for discrimination: H_0: \delta_0 = 0 vs. H_1: \delta_0 < 0, \;t = -1.81/0.265 = -6.83: reject.
  • The intercept -1.57 is the predicted wage of a man with zero education, experience and tenure: not meaningful.

The dummy variable trap

If we include both female and male and an intercept, then \;intercept = female + male\; exactly: perfect collinearity (MLR.3 fails).

Rule: with g categories, include g - 1 dummies plus the intercept.

Dummies without any other regressor

coef(summary(lm(wage ~ female, data = wage1)))
#>              Estimate Std. Error   t value      Pr(>|t|)
#> (Intercept)  7.099489  0.2100082 33.805777 8.971839e-134
#> female      -2.511830  0.3034092 -8.278688  1.041764e-15
tapply(wage1$wage, wage1$female, mean)     # group means
#>        0        1 
#> 7.099489 4.587659
  • The intercept is the mean wage of men (7.10) and \hat\delta_0 is the difference in group means (4.59 - 7.10 = -2.51).
  • The t test on the dummy is exactly the comparison-of-means test (assuming equal variances).
  • This gap ignores education, experience and tenure, so it is not a ceteris paribus effect.

A logarithmic dependent variable

w2 <- lm(lwage ~ female + educ + exper + expersq + tenure + tenursq, data = wage1)
round(coef(summary(w2))["female", ], 4)
#>   Estimate Std. Error    t value   Pr(>|t|) 
#>    -0.2965     0.0358    -8.2812     0.0000

With \log(wage), the coefficient is a proportionate difference: women earn about 100(0.297) = 29.7\% less than comparable men.

For such a large coefficient, use the exact formula 100[\exp(\hat\delta_0) - 1]. What is the exact percentage difference?

100[\exp(-0.2965) - 1] = -25.7\%. Women earn about 25.7% less than comparable men, not 29.7%.

Several dummies

Combining two dummies, letting them interact, and reading the model as four groups.

Two dummies: gender and marital status

w3 <- lm(wage ~ female + married, data = wage1)

\begin{aligned} \widehat{wage} &= \underset{\small (0.296)}{6.18} - \underset{\small (0.303)}{2.29}\,female + \underset{\small (0.310)}{1.34}\,married \\ & n = 526,\quad R^2 = 0.146 \end{aligned}

  • -2.29: the gap between women and men holding marital status fixed.
  • +1.34: the gap between married and single workers holding gender fixed.
  • This specification forces the marriage premium to be the same for men and women. Is that plausible?

Letting the effects interact

w4 <- lm(wage ~ female * married, data = wage1)

\begin{aligned} \widehat{wage} &= \underset{\small (0.361)}{5.17} - \underset{\small (0.474)}{0.556}\,female + \underset{\small (0.436)}{2.82}\,married \\ & - \underset{\small (0.608)}{2.86}\,female:married \\ & n = 526,\quad R^2 = 0.181 \end{aligned}

Group intercepts (= predicted mean wages):

single married
men 5.17 7.98
women 4.61 4.57
  • Married men earn $2.82 more than single men.
  • For women the marriage premium is 2.815 - 2.861 = -0.05: essentially zero.
  • The interaction coefficient (-2.86, t = -4.7) says the premium differs sharply by gender.

The same model as four groups

Define four mutually exclusive dummies and omit one:

wage1 <- transform(wage1,
  marrmale = (1 - female) * married, marrfem = female * married,
  singfem  = female * (1 - married))
w5 <- lm(lwage ~ marrmale + marrfem + singfem + educ + exper + expersq +
           tenure + tenursq, data = wage1)
round(coef(w5)[1:4], 4)
#> (Intercept)    marrmale     marrfem     singfem 
#>      0.3214      0.2127     -0.1983     -0.1104

With single men as the base group and all controls included:

  • married men earn about 21% more than single men,
  • married women about 19.8% less, single women about 11% less.

Interactive: the base group is only a reference

Switch the base group: every coefficient changes, but the four group intercepts (last column), the fitted values and R-squared do not. This is the cleanest way to show that the base group is a normalization, not an economic assumption.

Check your understanding

A researcher re-estimates the model with married women as the base group. What changes?

A) The fitted values and R^2

B) The coefficients, because each one is now a difference with respect to married women

C) Nothing at all

Choosing the base group is a normalization. The estimated differences between any two groups, the fitted values and R^2 are unchanged; only which difference each coefficient reports changes.

Different slopes

Interacting a dummy with a quantitative variable, and testing whether the groups differ at all.

Interacting a dummy with a quantitative variable

\begin{aligned} \log(wage) &= (\beta_0 + \delta_0\, female) + (\beta_1 + \delta_1\, female)\,educ + u\\ &= \beta_0 + \delta_0\, female + \beta_1\, educ + \delta_1\,(female \cdot educ) + u \end{aligned}

  • \delta_0: difference in intercepts
  • \delta_1: difference in slopes, i.e. in the return to education
  • H_0: \delta_1 = 0: the return to education is the same for men and women
  • H_0: \delta_0 = \delta_1 = 0: wages are identical for men and women at every education level (F test)
w6 <- lm(lwage ~ female * educ + exper + expersq +
           tenure + tenursq, data = wage1)
round(coef(summary(w6))[c("female", "female:educ"), ], 4)
#>             Estimate Std. Error t value Pr(>|t|)
#> female       -0.2268     0.1675 -1.3536   0.1764
#> female:educ  -0.0056     0.0131 -0.4260   0.6703

The return to education is 8.2% for men and 8.2 - 0.56 = 7.6\% for women. The difference is small and insignificant (t = -0.43).

Why is the female coefficient insignificant here?

In this model \hat\delta_0 = -0.227 with t = -1.35, while the simple dummy model gave -0.297 with t = -8.3. What happened?

\hat\delta_0 is now the gap at educ = 0, and nobody has zero education. Also, female and female\cdot educ are highly correlated, so both coefficients are imprecise.

Fix: center education at its mean (\overline{educ} = 12.56) before interacting:

wage1$educdev <- wage1$educ - mean(wage1$educ)
w7 <- lm(lwage ~ female * educdev + exper + expersq + tenure + tenursq, data = wage1)
round(coef(summary(w7))["female", ], 4)
#>   Estimate Std. Error    t value   Pr(>|t|) 
#>    -0.2967     0.0358    -8.2792     0.0000

Now the coefficient is the gender gap at the average education level: -0.297 with t = -8.3, exactly as in the model without the interaction.

Is there any difference between men and women?

Neither \hat\delta_0 nor \hat\delta_1 is significant on its own, but that is a statement about each coefficient. The question “are wages the same for men and women at every education level?” is a joint hypothesis:

H_0:\ \delta_0 = 0 \;\text{ and }\; \delta_1 = 0 \qquad\text{vs.}\qquad H_1:\ \delta_0 \neq 0 \;\text{ or }\; \delta_1 \neq 0

The restricted model simply drops female and female:educ, so this is an F test with q = 2:

car::linearHypothesis(w6, c("female = 0", "female:educ = 0"))[2, c("Df", "F", "Pr(>F)")]
#>   Df      F    Pr(>F)    
#> 2  2 34.325 1.002e-14 ***
#> ---
#> Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1

F(2, 518) = 34.3, p-value < 0.0001: reject H_0. Individually insignificant, jointly highly significant — exactly the collinearity story from Topic 6.

The Chow test: do all coefficients differ?

Interact the dummy with every regressor, and the unrestricted model is the same as running separate regressions for men and women:

H_0: \text{all } k+1 \text{ coefficients are the same for both groups} \qquad q = k + 1 

ur <- lm(lwage ~ female * (educ + exper + expersq + tenure + tenursq), data = wage1)
r  <- lm(lwage ~ educ + exper + expersq + tenure + tenursq, data = wage1)
anova(r, ur)[2, c("Df", "F", "Pr(>F)")]
#>   Df      F    Pr(>F)    
#> 2  6 14.997 7.654e-16 ***
#> ---
#> Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1

F = \frac{(93.911 - 79.920)/6}{79.920/514} = 15.0,\qquad p < 0.0001

Reject: the wage equation is not the same for the two groups. The Chow test says that they differ, not which coefficient differs.

Interactive: the same two lines, three ways

Switch to log(wage) and compare the “+ female dummy” and “+ female x educ” models. The picture barely changes: that is what an insignificant interaction looks like.

R toolkit for this topic

lm(wage ~ female + educ, data = wage1)          # dummy = difference in intercepts
lm(wage ~ female * married, data = wage1)       # both dummies + their interaction
lm(lwage ~ female * educ, data = wage1)         # different intercepts and slopes

# factors: R creates the dummies and picks a base group for you
wage1$group <- factor(ifelse(wage1$female == 1, "female", "male"))
wage1$group <- relevel(wage1$group, ref = "male")     # choose the base group
lm(wage ~ group + educ, data = wage1)

# joint test: are men and women identical in intercept and slope?
car::linearHypothesis(lm(lwage ~ female * educ, data = wage1),
                      c("female = 0", "female:educ = 0"))

Key takeaways

  1. A dummy turns qualitative information into a number: its coefficient is a difference in intercepts.
  2. With g categories use g-1 dummies plus an intercept, otherwise you fall into the dummy variable trap.
  3. The base group is a normalization: coefficients change with it, fitted values and R^2 do not.
  4. Interacting two dummies lets each group have its own intercept (e.g. the marriage premium differs by gender).
  5. Interacting a dummy with a quantitative variable gives different slopes; center the variable to make the dummy coefficient interpretable.
  6. With \log(y), use 100[\exp(\hat\delta_0)-1] for large gaps.
