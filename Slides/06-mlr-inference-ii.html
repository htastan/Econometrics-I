Warm-up: do parents’ education matter?

Birth weight (bwght, 1,191 babies) regressed on cigarettes, birth order, family income and both parents’ education:

estimate std. error t
motheduc −0.370 0.320 −1.16
fatheduc 0.472 0.283 1.67

Neither coefficient is significant at 5%. Can we conclude that parents’ education has no effect on birth weight?

A) Yes: two insignificant t tests mean both effects are zero

B) Not yet: the two variables are highly correlated, so we need a test of both coefficients together

Each t test asks about one coefficient while holding the other fixed. When motheduc and fatheduc move together, each one alone can look unimportant even if together they matter. We need a joint test: the F test. (Here, it turns out, the joint test also does not reject.)

Testing a linear combination

One restriction involving two coefficients, and the reparametrization trick that makes R do the work.

Is a year at a junior college worth a year at a university?

twoyear: \;\log(wage) = \beta_0 + \beta_1\, jc + \beta_2\, univ + \beta_3\, exper + u

jc: years at a 2-year college, univ: years at a 4-year university.

tw <- lm(lwage ~ jc + univ + exper, data = twoyear)

\begin{aligned} \widehat{\log(wage)} &= \underset{\small (0.0211)}{1.47} + \underset{\small (0.00683)}{0.0667}\,jc + \underset{\small (0.00231)}{0.0769}\,univ + \underset{\small (0.000157)}{0.00494}\,exper \\ & n = 6763,\quad R^2 = 0.222 \end{aligned}

H_0: \beta_1 = \beta_2 \;\;(\beta_1 - \beta_2 = 0) \qquad\text{vs.}\qquad H_1: \beta_1 < \beta_2

t = \frac{\hat\beta_1 - \hat\beta_2}{\text{se}(\hat\beta_1 - \hat\beta_2)}, \qquad \text{Var}(\hat\beta_1 - \hat\beta_2) = \text{Var}(\hat\beta_1) + \text{Var}(\hat\beta_2) - 2\,\text{Cov}(\hat\beta_1, \hat\beta_2)

The problem: the covariance is not in the standard output.

The trick: reparametrize the model

Define \theta_1 = \beta_1 - \beta_2, so \beta_1 = \theta_1 + \beta_2. Substituting:

\log(wage) = \beta_0 + \theta_1\, jc + \beta_2\,(jc + univ) + \beta_3\, exper + u = \beta_0 + \theta_1\, jc + \beta_2\, totcoll + \beta_3\, exper + u 

twoyear$totcoll <- twoyear$jc + twoyear$univ
tw2 <- lm(lwage ~ jc + totcoll + exper, data = twoyear)

\begin{aligned} \widehat{\log(wage)} &= \underset{\small (0.0211)}{1.47} - \underset{\small (0.00694)}{0.0102}\,jc + \underset{\small (0.00231)}{0.0769}\,totcoll + \underset{\small (0.000157)}{0.00494}\,exper \\ & n = 6763,\quad R^2 = 0.222 \end{aligned}

The coefficient on jc is \hat\theta_1: \;t = -0.0102/0.0069 = -1.47, one-sided p-value = 0.071.

There is some, but not strong, evidence that a year at a university is worth more than a year at a junior college.

Multiple restrictions: the F test

Restricted vs. unrestricted models, the F statistic, joint significance and the LM test.

Exclusion restrictions

Unrestricted model with k regressors:

y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \beta_3 x_3 + \beta_4 x_4 + \beta_5 x_5 + u \qquad (SSR_{ur},\; R^2_{ur})

H_0: \beta_3 = 0,\; \beta_4 = 0,\; \beta_5 = 0 \qquad H_1: H_0 \text{ is not true}

H_0 imposes q = 3 exclusion restrictions: x_3, x_4, x_5 have no effect on y once x_1, x_2 are controlled for. H_1: at least one of them is non-zero.

Restricted model (impose H_0):

y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + u \qquad (SSR_r,\; R^2_r)

Dropping variables can only increase the SSR. The question is whether it increases a lot.

The F statistic

F = \frac{(SSR_r - SSR_{ur})/q}{SSR_{ur}/(n-k-1)} \;\sim\; F_{q,\,n-k-1} \quad\text{under } H_0 \text{ (CLM assumptions)}

  • q = number of restrictions = numerator df = df_r - df_{ur}
  • n - k - 1 = denominator df, from the unrestricted model
  • F \geq 0 always
  • Reject H_0 if F > c, with c from F_{q,\,n-k-1}

R^2 form

Using SSR = SST(1-R^2):

F = \frac{(R^2_{ur} - R^2_r)/q}{(1 - R^2_{ur})/(n-k-1)}

Valid only when both models have the same dependent variable.

Same sample!

Both models must be estimated on the same observations. If some observations have missing values only for the excluded variables, drop them from the restricted model too.

Example: parents’ education and birth weight

ur <- lm(bwght ~ cigs + parity + faminc + motheduc + fatheduc, data = bwght)
r  <- lm(bwght ~ cigs + parity + faminc, data = model.frame(ur))  # same 1,191 babies

Unrestricted model

\begin{aligned} \widehat{bwght} &= \underset{\small (3.73)}{114.52} - \underset{\small (0.110)}{0.596}\,cigs + \underset{\small (0.659)}{1.79}\,parity + \underset{\small (0.0366)}{0.0560}\,faminc \\ & - \underset{\small (0.320)}{0.370}\,motheduc + \underset{\small (0.283)}{0.472}\,fatheduc \\ & n = 1191,\quad R^2 = 0.0387 \end{aligned}

Restricted model (under H_0: \beta_{motheduc} = \beta_{fatheduc} = 0)

\begin{aligned} \widehat{bwght} &= \underset{\small (1.66)}{115.47} - \underset{\small (0.109)}{0.598}\,cigs + \underset{\small (0.658)}{1.83}\,parity + \underset{\small (0.0324)}{0.0671}\,faminc \\ & n = 1191,\quad R^2 = 0.0364 \end{aligned}

Computing the F statistic

SSR_{ur} = 464{,}041, \;SSR_r = 465{,}167, \;q = 2, \;n - k - 1 = 1191 - 5 - 1 = 1185:

F = \frac{(465{,}167 - 464{,}041)/2}{464{,}041/1185} = 1.44 \;<\; c_{0.05} = 3.00 \;\Rightarrow\; \text{fail to reject } H_0

The same test in R

linearHypothesis(ur, c("motheduc = 0", "fatheduc = 0"))
#> Linear hypothesis test
#> 
#> Hypothesis:
#> motheduc = 0
#> fatheduc = 0
#> 
#> Model 1: restricted model
#> Model 2: bwght ~ cigs + parity + faminc + motheduc + fatheduc
#> 
#>   Res.Df    RSS Df Sum of Sq      F Pr(>F)
#> 1   1187 465167                           
#> 2   1185 464041  2    1125.7 1.4373  0.238

Parents’ education is jointly insignificant: p-value = 0.24.

Interactive: the F test

Jointly significant, individually insignificant

With highly correlated regressors, each t test can fail to reject while the F test rejects.

Press “Find a puzzling sample”. Both t tests fail to reject (0,0 is inside the blue box) but the F test rejects (0,0 is outside the orange ellipse). Then lower the correlation: the ellipse becomes rounder and the puzzle disappears. Typical case: several measures of firm performance in a CEO salary equation.

Relationship between t and F

For one restriction (q = 1) against a two-sided alternative, \;F = t^2. So the F test adds nothing for a single coefficient, and the t test is more flexible: it allows one-sided alternatives.

A two-sided t test gives t = -2.5. The F test of the same single restriction gives…

A) F = -2.5

B) F = 2.5

C) F = 6.25, with the same p-value as the two-sided t test

F = t^2 = 6.25. Since F is always non-negative, it cannot distinguish the direction: it corresponds to the two-sided t test.

Overall significance of a regression

H_0: \beta_1 = \beta_2 = \dots = \beta_k = 0 \qquad (\text{none of the regressors helps explain } y)

The restricted model is y = \beta_0 + u, with R^2_r = 0:

F = \frac{R^2/k}{(1 - R^2)/(n-k-1)} \;\sim\; F_{k,\,n-k-1}

R reports it at the bottom of summary(): for the birth weight model, F(5, 1185) = 9.55, p-value < 0.0001.

Low R², significant regression

R^2 = 0.039 is small, yet the regressors are jointly highly significant. A low R^2 does not mean the regression is useless.

General linear restrictions: rational house valuations

hprice1: are assessed values rational? If so, once the assessment is known, nothing else should help predict the price.

hr <- lm(lprice ~ lassess + llotsize + lsqrft + bdrms, data = hprice1)

\begin{aligned} \widehat{\log(price)} &= \underset{\small (0.570)}{0.264} + \underset{\small (0.151)}{1.04}\,lassess + \underset{\small (0.0386)}{0.00744}\,llotsize \\ & - \underset{\small (0.138)}{0.103}\,lsqrft + \underset{\small (0.0221)}{0.0338}\,bdrms \\ & n = 88,\quad R^2 = 0.773 \end{aligned}

H_0: \beta_1 = 1,\; \beta_2 = 0,\; \beta_3 = 0,\; \beta_4 = 0 \qquad (q = 4)

Rational valuations: the restricted model

Under H_0: \;\log(price) = \beta_0 + \log(assess) + u \;\Leftrightarrow\; \log(price) - \log(assess) = \beta_0 + u

hr0 <- lm(I(lprice - lassess) ~ 1, data = hprice1)
c(SSR_r = sum(resid(hr0)^2), SSR_ur = sum(resid(hr)^2))
#>    SSR_r   SSR_ur 
#> 1.880149 1.821529

F = \frac{(1.880 - 1.822)/4}{1.822/83} = 0.67 \;<\; c_{0.05} = 2.48

Fail to reject: no evidence against rational assessments.

Use the SSR form here

The dependent variable of the restricted model is different (\log(price) - \log(assess)), so the R^2 form of the F statistic cannot be used. In R: linearHypothesis(hr, c("lassess = 1", "llotsize = 0", "lsqrft = 0", "bdrms = 0")).

A large-sample test: the LM statistic

The Lagrange multiplier (score) statistic for q exclusion restrictions needs only the restricted model:

  1. Estimate the restricted model and save the residuals \tilde u.
  2. Regress \tilde u on all the regressors (including the excluded ones). Save its R^2_{\tilde u}.
  3. Compute \;LM = n\,R^2_{\tilde u} \;\stackrel{a}{\sim}\; \chi^2_q\; and reject H_0 if LM > c.

R toolkit for this topic

library(car)
ur <- lm(bwght ~ cigs + parity + faminc + motheduc + fatheduc, data = bwght)
linearHypothesis(ur, c("motheduc = 0", "fatheduc = 0"))    # F test, exclusion
summary(ur)$fstatistic                                    # overall significance

r  <- lm(bwght ~ cigs + parity + faminc, data = model.frame(ur))  # same sample!
anova(r, ur)                                              # F test via two models

# LM test
aux <- lm(resid(r) ~ cigs + parity + faminc + motheduc + fatheduc, data = model.frame(ur))
LM  <- nobs(aux) * summary(aux)$r.squared
pchisq(LM, df = 2, lower.tail = FALSE)

# linear combination: H0 beta_jc = beta_univ
linearHypothesis(lm(lwage ~ jc + univ + exper, data = twoyear), "jc = univ")

Key takeaways

  1. A linear combination such as \beta_1 - \beta_2 can be tested with a t test after reparametrizing the model.
  2. The F test compares SSR_r and SSR_{ur} for q restrictions: F \sim F_{q,\,n-k-1}.
  3. Variables can be jointly significant while individually insignificant, especially when they are correlated.
  4. Overall significance: F = \frac{R^2/k}{(1-R^2)/(n-k-1)}.
  5. The R^2 form works only when both models have the same dependent variable.
  6. The LM test = n R^2_{\tilde u} needs only the restricted model and is valid in large samples.
