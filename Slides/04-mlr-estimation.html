The ACT coefficient falls to about one-third after adding hsGPA. Why?

A) Adding a variable always makes the other coefficients smaller

B) High-ACT students also tend to have high hsGPA, so ACT alone picked up part of its effect

ACT and hsGPA are correlated (0.35), so alone ACT “gets credit” for hsGPA. Multiple regression compares students with the same hsGPA.

Why multiple regression?

Holding other factors fixed explicitly, and more flexible functional forms.

Holding other factors fixed explicitly

  • In simple regression, SLR.4 requires that all other factors in u are unrelated to x. This is often unrealistic.
  • Multiple regression lets us control for other observed factors that affect y.

Wage equation

wage = \beta_0 + \beta_1 educ + \beta_2 exper + u

\beta_1: the effect of education holding experience fixed.

Test scores

avgscore = \beta_0 + \beta_1 expend + \beta_2 avginc + u

Omitting avginc would put it in u, and it is correlated with spending.

Multiple regression also allows more flexible functional forms:

cons = \beta_0 + \beta_1 inc + \beta_2 inc^2 + u \qquad\Rightarrow\qquad \frac{\Delta cons}{\Delta inc} \approx \beta_1 + 2\beta_2\, inc

The marginal propensity to consume now depends on income. Here we cannot “hold inc^2 fixed” while changing inc.

The model with k explanatory variables

\Large y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_k x_k + u

\beta_0 \beta_j x_1,\dots,x_k u

Click each symbol.

Key assumption, MLR.4 (zero conditional mean):

E(u \mid x_1, x_2, \dots, x_k) = 0

For every combination of the x’s, the unobservables average to zero. For example, in the wage equation average ability must be the same for all combinations of educ and exper.

OLS estimation

The same minimization in more dimensions: fitting a plane, partialling out, goodness of fit.

Same principle, more dimensions

The sample regression function is \;\hat y = \hat\beta_0 + \hat\beta_1 x_1 + \dots + \hat\beta_k x_k

OLS chooses the k+1 estimates to minimize the sum of squared residuals:

\min_{\hat\beta_0,\dots,\hat\beta_k}\; \sum_{i=1}^n \big(y_i - \hat\beta_0 - \hat\beta_1 x_{i1} - \dots - \hat\beta_k x_{ik}\big)^2

This gives k+1 first-order conditions, the sample versions of E(u)=0 and E(x_j u)=0:

\sum_{i=1}^n \hat u_i = 0, \qquad \sum_{i=1}^n x_{ij}\,\hat u_i = 0 \quad (j = 1,\dots,k)

Geometry

With one regressor OLS fits a line. With two regressors it fits a plane in 3D space. With k regressors it fits a hyperplane that we can no longer draw.

Interpreting the estimates

data("gpa1")
coef(lm(colGPA ~ hsGPA + ACT, data = gpa1))
#> (Intercept)       hsGPA         ACT 
#> 1.286327767 0.453455885 0.009426012

\widehat{colGPA} = 1.29 + 0.453\, hsGPA + 0.0094\, ACT, \qquad n = 141

  • Holding ACT fixed, one more point of hsGPA raises the predicted colGPA by 0.453, almost half a point.
  • Equivalently: take two students A and B with the same ACT score. If A’s hsGPA is one point higher, we predict A’s colGPA to be 0.453 higher.
  • The intercept 1.29 is the prediction for hsGPA = 0 and ACT = 0. No such student exists, so it has no useful interpretation.

Fitted values, residuals and their properties

\hat y_i = \hat\beta_0 + \hat\beta_1 x_{i1} + \dots + \hat\beta_k x_{ik}, \qquad \hat u_i = y_i - \hat y_i

  • \hat u_i > 0: the model under-predicts y_i. \hat u_i < 0: it over-predicts.

The algebraic properties from simple regression carry over:

  1. \sum_i \hat u_i = 0, so \bar{\hat u} = 0 and \bar y = \bar{\hat y}
  2. \sum_i x_{ij}\hat u_i = 0 for every j: the residuals are uncorrelated with each regressor
  3. The point of means (\bar x_1, \dots, \bar x_k, \bar y) lies on the regression plane

“Partialling out”

With two regressors, the OLS slope on x_1 can be written as

\hat\beta_1 = \frac{\sum_i \hat r_{i1}\, y_i}{\sum_i \hat r_{i1}^2}

where \hat r_{i1} are the residuals from regressing x_1 on x_2: the part of x_1 not explained by x_2.

Simple vs. multiple regression estimates

Compare \tilde y = \tilde\beta_0 + \tilde\beta_1 x_1 with \hat y = \hat\beta_0 + \hat\beta_1 x_1 + \hat\beta_2 x_2. In general \tilde\beta_1 \neq \hat\beta_1, and in fact

\tilde\beta_1 = \hat\beta_1 + \hat\beta_2\,\tilde\delta_1

where \tilde\delta_1 is the slope from regressing x_2 on x_1.

When are the simple and the multiple regression estimates of the slope on x_1 equal? Select all that apply.

A) When \hat\beta_2 = 0: x_2 has no partial effect in the sample

B) When x_2 has a larger variance than x_1

C) When x_1 and x_2 are uncorrelated in the sample, so \tilde\delta_1 = 0

Both cases make the second term \hat\beta_2\tilde\delta_1 vanish. With gpa1: 0.0271 = 0.0094 + 0.453 \times 0.039.

Where that identity comes from

The simple regression slope is \;\tilde\beta_1 = \dfrac{\sum_i (x_{i1}-\bar x_1)\,y_i}{\sum_i (x_{i1}-\bar x_1)^2}. Write y_i with the multiple regression fit, y_i = \hat\beta_0 + \hat\beta_1x_{i1} + \hat\beta_2x_{i2} + \hat u_i:

\tilde\beta_1 = \frac{\sum_i (x_{i1}-\bar x_1)\big(\hat\beta_0 + \hat\beta_1 x_{i1} + \hat\beta_2 x_{i2} + \hat u_i\big)}{\sum_i (x_{i1}-\bar x_1)^2}

Three OLS algebra facts do the work: \sum_i(x_{i1}-\bar x_1) = 0 kills the intercept, \sum_i (x_{i1}-\bar x_1)\hat u_i = 0 kills the residual term, and the \hat\beta_1 term leaves exactly \hat\beta_1. What survives is

\tilde\beta_1 = \hat\beta_1 + \hat\beta_2\,\underbrace{\frac{\sum_i (x_{i1}-\bar x_1)x_{i2}}{\sum_i (x_{i1}-\bar x_1)^2}}_{\tilde\delta_1\;=\;\text{slope of } x_2 \text{ on } x_1}

This is a sample identity — no assumptions yet. Take expectations and the same algebra gives the omitted variable bias formula on the next slides.

Goodness of fit

The same definitions as before: SST = SSE + SSR and

R^2 = \frac{SSE}{SST} = 1 - \frac{SSR}{SST} = \big[\text{Corr}(y, \hat y)\big]^2

R^2 is the share of the sample variation in y explained jointly by x_1, \dots, x_k. For gpa1: R^2 = 0.176.

R² never decreases when you add a regressor

Adding a variable can only lower the SSR (or leave it unchanged), so R^2 goes up, even if the new variable is pure noise. So R^2 alone is a poor guide for choosing regressors. We will use the adjusted R^2 and F tests later.

Regression through the origin (\tilde y = \tilde\beta_1 x_1 + \dots + \tilde\beta_k x_k): R^2 can be negative, and the estimators are biased if the true intercept is not zero.

Statistical properties

MLR.1–MLR.4 and unbiasedness, irrelevant variables, and omitted variable bias.

Assumptions MLR.1–MLR.4

MLR.1 · Linear in parameters

y = \beta_0 + \beta_1 x_1 + \dots + \beta_k x_k + u

MLR.2 · Random sampling

\{(x_{i1},\dots,x_{ik},y_i): i=1,\dots,n\} is a random sample.

MLR.3 · No perfect collinearity

No x is constant, and no exact linear relationship holds among the x’s. They may be correlated, just not perfectly.

MLR.4 · Zero conditional mean

E(u \mid x_1, \dots, x_k) = 0. It fails with a wrong functional form, omitted variables correlated with the x’s, or measurement error.

Theorem 3.1: unbiasedness of OLS

Under MLR.1–MLR.4, \;E(\hat\beta_j) = \beta_j for j = 0, 1, \dots, k.

Including an irrelevant variable

Suppose the true model is y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + u, but we also include x_3 with \beta_3 = 0 (overspecification).

  • All estimators remain unbiased: E(\hat\beta_1)=\beta_1, E(\hat\beta_2)=\beta_2 and E(\hat\beta_3)=0.
  • But the variances of the other estimators can increase (see multicollinearity below).

Omitting a relevant variable is worse

Leaving out a variable whose coefficient is not zero (underspecification) generally makes OLS biased.

Omitted variable bias: the formula

True model: y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + u. We omit x_2 and estimate \tilde y = \tilde\beta_0 + \tilde\beta_1 x_1.

Using \tilde\beta_1 = \hat\beta_1 + \hat\beta_2\tilde\delta_1 and taking expectations:

E(\tilde\beta_1) = \beta_1 + \beta_2\,\tilde\delta_1 \qquad\Longrightarrow\qquad \text{Bias}(\tilde\beta_1) = \beta_2\,\tilde\delta_1

where \tilde\delta_1 is the slope from regressing x_2 on x_1.

\text{Corr}(x_1,x_2) > 0 \text{Corr}(x_1,x_2) < 0
\beta_2 > 0 positive bias negative bias
\beta_2 < 0 negative bias positive bias

The bias is zero only if \beta_2 = 0 or x_1 and x_2 are uncorrelated.

Interactive: omitted variable bias

Example: ability bias in the wage equation

wage = \beta_0 + \beta_1 educ + \beta_2 abil + u

Ability is unobserved, so we estimate wage = \beta_0 + \beta_1 educ + v with v = \beta_2 abil + u.

What is the likely direction of the bias in \tilde\beta_1?

A) Upward: \beta_2 > 0 and ability is positively correlated with education

B) Downward: ability lowers wages

C) No bias, because ability is unobserved

More able people earn more (\beta_2>0) and tend to get more schooling (\text{Corr}>0). The simple regression overstates the return to education: part of the ability effect is attributed to education. Being unobserved is exactly what causes the problem.

More than two regressors: if the omitted x3 is correlated with x1 only, all the estimated slopes are generally biased, unless x1 and x2 are uncorrelated.

The variance of OLS

MLR.5, multicollinearity, standard errors and the Gauss–Markov theorem.

MLR.5 and the Gauss–Markov assumptions

MLR.5 · Homoskedasticity: \;\text{Var}(u \mid x_1, \dots, x_k) = \sigma^2

MLR.1–MLR.5 together are the Gauss–Markov assumptions for cross-sectional data. MLR.4 and MLR.5 can be written as

E(y\mid \mathbf x) = \beta_0 + \beta_1 x_1 + \dots + \beta_k x_k, \qquad \text{Var}(y\mid \mathbf x) = \sigma^2

Theorem 3.2: sampling variances of the OLS slopes

\text{Var}(\hat\beta_j) = \frac{\sigma^2}{SST_j\,(1 - R_j^2)}, \qquad j = 1,\dots,k

SST_j = \sum_i (x_{ij} - \bar x_j)^2 is the total variation in x_j, and R_j^2 is the R^2 from regressing x_j on all other regressors.

Three drivers: the error variance \sigma^2 (↑ var), the variation in x_j (↓ var), and how well the other x’s explain x_j (R_j^2 ↑ var).

Multicollinearity: the intuition

A firm always runs TV and radio ads in the same weeks. Sales rise in those weeks.

  • Was it the TV ads or the radio ads? The data never show one without the other.
  • To separate the two effects we need weeks where one changes and the other does not.
  • The fewer such weeks, the less information we have, and the noisier the estimates.

Link to the formula

By partialling out, \hat\beta_1 uses only \hat r_{i1}, the part of x_1 not explained by the other regressors. Its total variation is

\textstyle\sum_i \hat r_{i1}^2 = SST_1\,(1-R_1^2)

and this is the denominator of \text{Var}(\hat\beta_1).

Variance inflation factor

VIF_1 = 1/(1-R_1^2): how many times larger \text{Var}(\hat\beta_1) is than it would be if x_1 were uncorrelated with the other regressors. A common rule of thumb flags VIF > 10, but there is no strict cutoff.

Interactive: multicollinearity

Suggested sequence: start at 0, then 0.5, 0.9, 0.99 and finally 1. Point to the red lines in the left panel: they are the only variation that identifies beta1. At 0.99 about 2% of the information is left and the variance is about 50 times larger. Also stress that multicollinearity does not cause bias.

Estimating \sigma^2 and standard errors

\hat\sigma^2 = \frac{\sum_i \hat u_i^2}{n - k - 1} = \frac{SSR}{n - k - 1}, \qquad \text{se}(\hat\beta_j) = \frac{\hat\sigma}{\sqrt{SST_j\,(1 - R_j^2)}}

  • Degrees of freedom: n - (k+1) = observations − estimated parameters. The k+1 first-order conditions put k+1 restrictions on the residuals.
  • \hat\sigma is the standard error of the regression (SER). It can rise or fall when a variable is added.

The Gauss–Markov theorem

Theorem 3.4 (Gauss–Markov)

Under MLR.1–MLR.5, the OLS estimators \hat\beta_0, \hat\beta_1, \dots, \hat\beta_k are the best linear unbiased estimators (BLUE) of \beta_0, \beta_1, \dots, \beta_k.

  • Best: smallest variance
  • Linear: \tilde\beta_j = \sum_i w_{ij}\, y_i, where the weights may depend on the x’s. OLS has w_{ij} = \hat r_{ij}/\sum_i \hat r_{ij}^2.
  • Unbiased: E(\tilde\beta_j) = \beta_j

Why it matters: if the assumptions hold, there is no need to look for another linear unbiased estimator.

  • If MLR.4 fails, OLS is biased.
  • If MLR.5 fails, OLS is still unbiased but no longer “best” (Week 12).

Check your understanding

A researcher adds a variable that is highly correlated with x_1 but has no effect on y. What happens to \hat\beta_1?

A) It becomes biased

B) Nothing at all

C) It stays unbiased, but its variance increases because R_1^2 goes up

D) Its variance decreases because the model has more information

An irrelevant variable does not cause bias, but it raises R_1^2 and so \text{Var}(\hat\beta_1) = \sigma^2/[SST_1(1-R_1^2)]. There is a trade-off: omitting a relevant variable causes bias, while including an irrelevant one costs precision.

R toolkit for this topic

res <- lm(colGPA ~ hsGPA + ACT, data = gpa1)   # multiple regression
summary(res)                                      # estimates, se, R^2

# partialling out: the same coefficient on hsGPA

# omitted variable bias identity: beta_tilde = beta_hat + beta2_hat * delta

coef(res)["hsGPA"] + coef(res)["ACT"] * delta     # = simple slope on hsGPA
car::vif(res)                                     # variance inflation factors

Key takeaways

  1. Multiple regression holds other observed factors fixed explicitly.
  2. \hat\beta_j is the effect of x_j after partialling out the other x’s.
  3. Under MLR.1–MLR.4, OLS is unbiased. MLR.3 rules out only perfect collinearity.
  4. Omitted variable bias = \beta_2\tilde\delta_1. Its sign follows from the 2\times 2 table.
  5. \text{Var}(\hat\beta_j) = \sigma^2/[SST_j(1-R_j^2)]. Multicollinearity inflates it.
  6. Under MLR.1–MLR.5, OLS is BLUE (Gauss–Markov).
