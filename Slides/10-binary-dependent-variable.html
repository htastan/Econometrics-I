Warm-up: a strange prediction

A bank estimates by OLS: \;\widehat{deny} = -0.080 + 0.604\;(P/I\ ratio), where deny = 1 if the mortgage application was rejected.

For an applicant with a P/I ratio of 0.05 the model predicts -0.05. What does that mean?

A) The applicant will certainly be accepted

B) Nothing sensible: a probability cannot be negative. The straight line is the problem.

C) The model is estimated incorrectly

Nothing is wrong with the estimation: OLS did its job. The problem is the model: a straight line eventually leaves the interval [0,1], while a probability cannot. This is the starting point for logit and probit.

The linear probability model

A regression whose fitted value is a probability, estimated by plain OLS.

When y is binary

y \in \{0, 1\}: in the labor force or not, mortgage denied or not, owns a house or not, defaults or not. y = 1 is called a success.

Since y takes only the values 0 and 1,

E(y \mid \mathbf x) = 1\cdot P(y = 1\mid \mathbf x) + 0\cdot P(y=0\mid \mathbf x) = P(y = 1 \mid \mathbf x) \equiv p(\mathbf x)

So the usual regression assumption becomes a model for a probability:

\boxed{\;P(y = 1\mid \mathbf x) = \beta_0 + \beta_1 x_1 + \dots + \beta_k x_k\;}

This is the linear probability model (LPM). It is estimated by plain OLS.

Interpretation

\beta_j = \dfrac{\Delta P(y=1\mid \mathbf x)}{\Delta x_j}: the change in the probability of success for a one-unit increase in x_j, ceteris paribus. The fitted value \hat y is a predicted probability.

Example: married women’s labor force participation

mroz (n = 753, 1975): inlf = 1 if the woman worked for a wage outside the home.

lpm <- lm(inlf ~ nwifeinc + educ + exper + I(exper^2) + age + kidslt6 + kidsge6,
          data = mroz)

\begin{aligned} \widehat{inlf} &= \underset{\small (0.154)}{0.586} - \underset{\small (0.00145)}{0.00341}\,nwifeinc + \underset{\small (0.00738)}{0.0380}\,educ + \underset{\small (0.00567)}{0.0395}\,exper \\ & - \underset{\small (0.000185)}{0.000596}\,exper^2 - \underset{\small (0.00248)}{0.0161}\,age - \underset{\small (0.0335)}{0.262}\,kidslt6 + \underset{\small (0.0132)}{0.0130}\,kidsge6 \\ & n = 753,\quad R^2 = 0.264 \end{aligned}

Interpreting the LPM

  • educ: one more year of schooling raises the participation probability by 0.038, that is 3.8 percentage points, ceteris paribus.
  • nwifeinc is in $1,000s: $10,000 more husband’s income lowers the probability by 10 \times 0.0034 = 0.034, i.e. 3.4 pp.
  • kidslt6: one more young child lowers it by 26.2 pp. kidsge6 is insignificant.

Percentage points, not percent

A coefficient of 0.038 means +3.8 percentage points (e.g. from 50% to 53.8%), not “3.8% more likely”.

Two women differ only in that one has one more child under six. By how much does the model say their participation probabilities differ?

0.262, i.e. 26.2 percentage points. The model assumes this is the same whether the change is from 0 to 1 child or from 3 to 4, which is not realistic.

Three problems

Impossible predictions, constant marginal effects, and unavoidable heteroskedasticity.

Problem 1: predictions outside [0, 1]

Switch between the two panels. First: 16 women have negative predicted probabilities and 17 above one, out of 753. Second: the residual variance follows p(1-p) closely, so the LPM is always heteroskedastic.

Problem 2: constant marginal effects

The LPM forces the effect of x_j to be the same everywhere:

  • going from 0 to 1 young child lowers participation by 26.2 pp,
  • and so does going from 3 to 4.

It is far more plausible that the first child has a large effect and later children smaller ones. Push the model far enough and it must leave [0,1].

Why the LPM still survives

Near the middle of the data the straight line is often a good approximation. In mroz, 96% of the women have no child under six or exactly one, so the coefficient on kidslt6 is mostly the effect of the first child. Just do not extrapolate.

Problem 3: heteroskedasticity

For a Bernoulli variable, the variance is determined by the mean:

\text{Var}(y \mid \mathbf x) = \text{Var}(u\mid \mathbf x) = p(\mathbf x)\,[1 - p(\mathbf x)]

Since p(\mathbf x) changes with \mathbf x, MLR.5 always fails in the LPM.

  • OLS is still unbiased and consistent (MLR.1–4 can hold), but it is no longer BLUE.
  • The usual standard errors are invalid: always use heteroskedasticity-robust standard errors (Week 12), or weighted least squares with \hat h_i = \hat y_i(1-\hat y_i).
coeftest(lpm, vcov = vcovHC(lpm, type = "HC1"))   # lmtest + sandwich

Logit and probit

An S-shaped model, maximum likelihood, predicted probabilities, marginal effects and inference.

Keeping probabilities between 0 and 1

Replace the straight line by a function G(\cdot) that always returns a number between 0 and 1:

P(y = 1 \mid \mathbf x) = G(\beta_0 + \beta_1x_1 + \dots + \beta_kx_k)

Logit

G(z) = \Lambda(z) = \frac{1}{1 + e^{-z}}

the logistic cdf

Probit

G(z) = \Phi(z)

the standard normal cdf

Both are S-shaped (sigmoid) and strictly increasing. They are estimated by maximum likelihood, not OLS. The two give very similar fitted probabilities.

What maximum likelihood does

OLS minimizes the sum of squared residuals. That makes no sense here: the model does not predict y_i, it assigns a probability to what we observe.

f(y_i \mid \mathbf x_i;\boldsymbol\beta) = \underbrace{[G(\mathbf x_i\boldsymbol\beta)]^{y_i}}_{\text{used when } y_i = 1} \cdot \underbrace{[1 - G(\mathbf x_i\boldsymbol\beta)]^{1-y_i}}_{\text{used when } y_i = 0}

Observations are independent, so the probability of the whole sample is the product of these terms. Taking logs turns it into a sum:

\log L(\boldsymbol\beta) = \sum_{i=1}^n \Big\{ y_i \log G(\mathbf x_i\boldsymbol\beta) + (1-y_i)\log\big[1 - G(\mathbf x_i\boldsymbol\beta)\big] \Big\}

The maximum likelihood estimator \hat{\boldsymbol\beta} is the value that makes the data we actually observed as likely as possible. There is no formula for it: R maximizes \log L numerically. Every term is a log of a probability, so \log L < 0 and “bigger” means “less negative”.

Interactive: what the likelihood maximizes

Start away from the MLE and watch the two panels. Top: the curve is too flat or too steep and the denied application (red) gets a low probability. Bottom: log L as a function of beta1 with beta0 held fixed, a hill with a single peak. Press “jump to the MLE”: log L = -795.7 at beta0 = -4.13, beta1 = 5.37. Any other pair makes the observed 2,380 decisions less likely.

Interactive: the logit curve

Move beta1: the curve gets steeper, never leaving [0,1]. Move x: the marginal effect is largest at p = 0.5 and vanishes in the tails. This is why beta1 is not a marginal effect, and why we must say “at which x?” when reporting effects.

Example: mortgage applications (HMDA)

2,380 applications in Boston, 1990. deny = 1 if the application was rejected; P/I ratio = payments / income.

lpm_h <- lm(deny ~ pirat + black, data = hmda)
logit_h <- glm(deny ~ pirat + black, data = hmda, family = binomial(link = "logit"))
round(cbind(LPM = coef(lpm_h), logit = coef(logit_h)), 3)
#>                LPM  logit
#> (Intercept) -0.091 -4.126
#> pirat        0.559  5.370
#> black        0.177  1.273
  • LPM: holding the P/I ratio fixed, being black raises the rejection probability by 17.7 percentage points.
  • Logit: the coefficients are positive and significant, but 1.27 is not a probability change. We must compute predicted probabilities.

Predicted probabilities

\begin{aligned} \widehat{P(deny = 1\mid \mathbf{x})} &= \Lambda\left( - \underset{\small (0.268)}{4.13} + \underset{\small (0.728)}{5.37}\,pirat + \underset{\small (0.146)}{1.27}\,black \right) \end{aligned} 

nd <- data.frame(pirat = 0.3, black = c(0, 1))
round(predict(logit_h, nd, type = "response"), 4)
#>      1      2 
#> 0.0749 0.2241
  • White applicant with P/I = 0.3: \;\Lambda(-4.13 + 5.37(0.3)) = 0.075, i.e. 7.5%
  • Black applicant, same ratio: \;\Lambda(-4.13 + 5.37(0.3) + 1.27) = 0.224, i.e. 22.4%

The estimated difference is 14.9 percentage points at this P/I ratio. Note that, unlike in the LPM, the gap depends on the P/I ratio.

Interactive: three models, one data set

Start with the LPM alone and move the P/I slider to a low value to get a negative probability. Then switch on logit and probit: the two curves are nearly indistinguishable. Turn on the black dummy and compare the predicted probabilities for the two groups at P/I = 0.3 (7.5% vs 22.4%).

Marginal effects in logit and probit

\frac{\partial P(y=1\mid \mathbf x)}{\partial x_j} = g(\beta_0 + \beta_1x_1 + \dots + \beta_kx_k)\,\beta_j, \qquad g(z) = \frac{dG(z)}{dz}

  • The effect depends on where it is evaluated: the same \beta_j gives different effects at different \mathbf x.
  • Common choices: the effect at the sample means, or the average partial effect (the average of the individual effects).
  • The sign of \beta_j and the z statistic can be read directly; the magnitude cannot.

For mroz, the average partial effect of one more year of education is 0.0395 (logit) and 0.0394 (probit) — almost exactly the LPM coefficient, 0.038. Near the center of the data the three models agree.

Inference: z statistics and the LR test

Maximum likelihood estimators are consistent and asymptotically normal, so inference works exactly as before, with the normal distribution in place of the t:

z = \frac{\hat\beta_j - a_j}{\text{se}(\hat\beta_j)} \;\stackrel{a}{\sim}\; N(0,1) \qquad |z| > 1.96 \Rightarrow \text{reject at 5\%}

R prints z value instead of t value for exactly this reason.

For q restrictions at once there is no SSR to compare, so we compare log-likelihoods instead:

LR = 2\,(\log L_{ur} - \log L_{r}) \;\stackrel{a}{\sim}\; \chi^2_q \qquad H_0: \text{the } q \text{ restrictions hold}

Imposing restrictions can only lower the maximum, so LR \geq 0. This is the likelihood-based counterpart of the F test.

Example: are children jointly significant?

f <- inlf ~ nwifeinc + educ + exper + I(exper^2) + age + kidslt6 + kidsge6
ur <- glm(f, data = mroz, family = binomial(link = "logit"))
r  <- update(ur, . ~ . - kidslt6 - kidsge6)          # H0: both coefficients are 0
c(logL_ur = logLik(ur), logL_r = logLik(r))
#>   logL_ur    logL_r 
#> -401.7652 -432.7764

LR = 2\,[-401.77 - (-432.78)] = 62.02 \;\sim\; \chi^2_2, \qquad c_{0.05} = 5.99,\qquad p < 0.0001 

lmtest::lrtest(r, ur)[2, 4:5]     # the same test in one line
#>    Chisq Pr(>Chisq)    
#> 2 62.023  3.404e-14 ***
#> ---
#> Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1

Reject H_0: the number of children matters. (kidsge6 alone is insignificant, z = 0.80; kidslt6 carries the joint result.)

Goodness of fit

Pseudo R^2 (McFadden)

1 - \frac{\log L}{\log L_0}

\log L_0 comes from the model with only an intercept. For mroz: 1 - (-401.77)/(-514.87) = 0.220.

Percent correctly predicted

Predict \tilde y_i = 1 when \hat p_i > 0.5 and compare with y_i. For mroz: 73.6%.

Read the percentage with care

In the HMDA data only 12% of applications are denied. A model that always predicts “approved” is right 88% of the time, and the logit gets 88.3% — almost the same. Always compare with the share of the most common outcome.

Check: reading a logit coefficient

In a logit model \hat\beta_{educ} = 0.22. What can we say?

A) One more year of education raises the probability by 22 percentage points

B) One more year raises the probability by 0.22 percentage points

C) Education raises the probability; the size of the effect depends on the person’s other characteristics

In a nonlinear model the coefficient is not a marginal effect. Multiply by g(\cdot), which is largest for people whose predicted probability is near 0.5.

LPM or logit?

LPM

  • estimated by OLS, coefficients are directly interpretable
  • easy to extend (fixed effects, IV, …) − impossible probabilities, constant effects, heteroskedasticity

Logit / probit

  • probabilities always in (0,1), effects taper off
  • the standard tool for classification in machine learning − coefficients need extra work (marginal effects), maximum likelihood

In practice

For effects near the center of the data the two approaches usually agree. Report robust standard errors with the LPM, and predicted probabilities or average partial effects with logit.

R toolkit for this topic

lpm <- lm(inlf ~ educ + exper + kidslt6, data = mroz)        # LPM
lmtest::coeftest(lpm, vcov = sandwich::vcovHC(lpm, "HC1"))    # robust se (needed!)

lg <- glm(deny ~ pirat + black, data = hmda, family = binomial(link = "logit"))
pr <- glm(deny ~ pirat + black, data = hmda, family = binomial(link = "probit"))
summary(lg)

predict(lg, data.frame(pirat = 0.3, black = 1), type = "response")   # probability
mean(dlogis(predict(lg)) * coef(lg)["pirat"])                        # average partial effect
table(actual = hmda$deny, predicted = as.numeric(fitted(lg) > 0.5))  # classification

Key takeaways

  1. With a binary y, \;E(y\mid \mathbf x) = P(y = 1\mid \mathbf x).
  2. In the LPM, \beta_j is the change in the probability in percentage points.
  3. Problems: predictions outside [0,1], constant marginal effects, and necessary heteroskedasticity → use robust standard errors.
  4. Logit and probit keep the probability in (0,1) with an S-shaped G(\cdot), estimated by maximum likelihood.
  5. Their coefficients are not marginal effects: compute g(\mathbf x\beta)\beta_j or predicted probabilities.
  6. Near the center of the data the LPM is often a good approximation.
