Warm-up: could it be zero?

In the wage1 regression of \log(wage) on educ, exper and tenure, the coefficient on experience is

\hat\beta_{exper} = 0.0041, \qquad \text{se}(\hat\beta_{exper}) = 0.0017

Could the true effect of experience be zero, and we just got an unlucky sample?

A) No, the estimate is positive, so the true effect must be positive

B) Yes, and there is no way to judge how likely that is

C) It is possible, but the estimate is about 2.4 standard errors away from 0, which would be unusual if the true effect were zero

Estimates vary from sample to sample, so a positive estimate does not prove a positive effect. But we can measure the distance from zero in standard errors: 0.0041/0.0017 \approx 2.4. Today we turn this idea into a formal t test with a known probability of error.

Sampling distributions

One more assumption (normality) turns the estimates into a distribution we can test with.

Assumption MLR.6: normality

To test hypotheses we need the full sampling distribution of \hat\beta_j, not only its mean and variance.

MLR.6 · Normality

The population error u is independent of x_1, \dots, x_k and normally distributed: \;u \sim \text{Normal}(0, \sigma^2).

  • MLR.6 is stronger than MLR.4 and MLR.5: it implies both.
  • MLR.1–MLR.6 are the classical linear model (CLM) assumptions. Under them, OLS is the minimum-variance unbiased estimator among all estimators, not only linear ones.
  • Compactly: \;y \mid \mathbf x \sim \text{Normal}(\beta_0 + \beta_1 x_1 + \dots + \beta_k x_k,\; \sigma^2)

Is normality reasonable?

Argument for

u is the sum of many unobserved factors. By the central limit theorem, a sum of many independent factors is approximately normal.

Arguments against

  • The factors may not enter additively.
  • Some variables cannot be normal: wages are positive and skewed, and minimum wage laws pile up observations.
  • Normality is an empirical question. A transformation such as \log(wage) often makes the distribution much closer to normal.
  • In large samples we can drop MLR.6 altogether: the t statistic is then approximately normal anyway (Week 6).

Sampling distributions of the OLS estimators

Theorem 4.1: normal sampling distributions

Under MLR.1–MLR.6, conditional on the x’s:

\hat\beta_j \sim \text{Normal}\big(\beta_j,\; \text{Var}(\hat\beta_j)\big) \qquad\Rightarrow\qquad \frac{\hat\beta_j - \beta_j}{\text{sd}(\hat\beta_j)} \sim \text{Normal}(0,1)

Why: \hat\beta_j is a linear combination of the errors, and linear combinations of normal variables are normal.

Theorem 4.2: the t distribution

Replacing the unknown sd by the estimated se:

\frac{\hat\beta_j - \beta_j}{\text{se}(\hat\beta_j)} \sim t_{n-k-1}

The t distribution has fatter tails than the normal because sigma-hat is itself estimated. As n-k-1 grows it approaches the standard normal. Show this in the t explorer by switching on N(0,1) and lowering df.

Testing a single parameter: the t test

A five-step recipe, then right-tail, left-tail and two-sided examples, p-values and significance.

The recipe

1 Hypotheses H_0: \beta_j = a_j and an alternative H_1

2 Significance level \alpha = P(reject H_0 when it is true), e.g. 5%

3 Test statistic t = (\hat\beta_j - a_j)/\text{se}(\hat\beta_j)

4 Critical value c from t_{n-k-1} for the chosen \alpha

5 Decision Reject H_0 if t falls in the rejection region

Alternative Rejection rule c at 5%, large df
H_1: \beta_j > a_j (right tail) t > c 1.645
H_1: \beta_j < a_j (left tail) t < -c 1.645
H_1: \beta_j \neq a_j (two-sided) \lvert t\rvert > c 1.96

Remember

Hypotheses are statements about the population parameters \beta_j, never about the estimates \hat\beta_j.

Right-tail test: from R output to equation

data("wage1")
res <- lm(log(wage) ~ educ + exper + tenure, data = wage1)
round(summary(res)$coefficients, 5)
#>             Estimate Std. Error  t value Pr(>|t|)
#> (Intercept)  0.28436    0.10419  2.72923  0.00656
#> educ         0.09203    0.00733 12.55525  0.00000
#> exper        0.00412    0.00172  2.39144  0.01714
#> tenure       0.02207    0.00309  7.13307  0.00000

The same results in equation form, with standard errors in parentheses under the estimates:

\begin{aligned} \widehat{\log(wage)} &= \underset{\small (0.104)}{0.284} + \underset{\small (0.00733)}{0.0920}\,educ + \underset{\small (0.00172)}{0.00412}\,exper + \underset{\small (0.00309)}{0.0221}\,tenure \\ & n = 526,\quad R^2 = 0.316 \end{aligned}

Estimate column → the coefficients. Std. Error column → the numbers in parentheses. This is how results are reported in papers and in exams.

Right-tail test: the return to experience

\begin{aligned} \widehat{\log(wage)} &= \underset{\small (0.104)}{0.284} + \underset{\small (0.00733)}{0.0920}\,educ + \underset{\small (0.00172)}{0.00412}\,exper + \underset{\small (0.00309)}{0.0221}\,tenure \\ & n = 526,\quad R^2 = 0.316 \end{aligned}

H_0: \beta_{exper} = 0\; vs. \;H_1: \beta_{exper} > 0, \quad df = n - k - 1 = 526 - 3 - 1 = 522

t_{exper} = \frac{\hat\beta_{exper}}{\text{se}(\hat\beta_{exper})} = \frac{0.00412}{0.00172} = 2.39

One-sided critical values from t_{522}: \;c_{0.05} = 1.648,\;\; c_{0.01} = 2.334

2.39 > 2.334: reject H_0 at the 1% level. Holding education and tenure fixed, experience has a statistically significant positive effect on wages. Economically, one more year of experience raises the wage by about 0.4%.

Left-tail test: carrying out the test

\begin{aligned} \widehat{math10} &= \underset{\small (6.11)}{2.27} + \underset{\small (0.000100)}{0.000459}\,totcomp + \underset{\small (0.0398)}{0.0479}\,staff - \underset{\small (0.000215)}{0.000198}\,enroll \\ & n = 408,\quad R^2 = 0.0541 \end{aligned}

Do larger schools hurt performance? \;H_0: \beta_{enroll} = 0\; vs. \;H_1: \beta_{enroll} < 0, \quad df = 408 - 4 = 404

t_{enroll} = \frac{-0.000198}{0.000215} = -0.92 \;>\; -c_{0.05} = -1.65

Fail to reject H_0 at 5%. There is no evidence that, holding teacher pay and staff fixed, school size affects the pass rate.

Note the scale

The coefficients on totcomp and enroll look tiny because these variables are measured in dollars and students. A change of one dollar or one student is small.

Left-tail test: a level-log model

Maybe a percentage change in enrollment is more natural:

m2 <- lm(math10 ~ log(totcomp) + log(staff) + log(enroll), data = meap93)

\begin{aligned} \widehat{math10} &= - \underset{\small (48.70)}{207.66} + \underset{\small (4.06)}{21.16}\,\log(totcomp) + \underset{\small (4.19)}{3.98}\,\log(staff) - \underset{\small (0.693)}{1.27}\,\log(enroll) \\ & n = 408,\quad R^2 = 0.0654 \end{aligned}

t_{\log(enroll)} = \frac{-1.27}{0.693} = -1.83 \;<\; -c_{0.05} = -1.65

Reject H_0 at 5% in favor of \beta_{\log(enroll)} < 0. A 10% larger enrollment lowers the predicted pass rate by about 1.27 \times 10/100 = 0.13 percentage points: statistically significant, but economically small.

Testing other values: H_0: \beta_j = a_j

t = \frac{\hat\beta_j - a_j}{\text{se}(\hat\beta_j)} = \frac{\text{estimate} - \text{hypothesized value}}{\text{standard error}}

Campus crime (campus, 97 universities): does crime rise more than proportionally with university size?

data("campus")
cr <- lm(log(crime) ~ log(enroll), data = campus)

\begin{aligned} \widehat{\log(crime)} &= - \underset{\small (1.03)}{6.63} + \underset{\small (0.110)}{1.27}\,\log(enroll) \\ & n = 97,\quad R^2 = 0.585 \end{aligned}

H_0: \beta_1 = 1 vs. H_1: \beta_1 > 1: \quad t = \dfrac{1.27 - 1}{0.110} \approx 2.46 > c_{0.05} = 1.66\; → reject H_0.

Testing other values: house prices and pollution

hprice2 (506 communities): is the elasticity of house prices with respect to air pollution (nox) equal to −1?

data("hprice2")
hp <- lm(log(price) ~ log(nox) + log(dist) + rooms + stratio, data = hprice2)

\begin{aligned} \widehat{\log(price)} &= \underset{\small (0.318)}{11.08} - \underset{\small (0.117)}{0.954}\,\log(nox) - \underset{\small (0.0431)}{0.134}\,\log(dist) \\ & + \underset{\small (0.0185)}{0.255}\,rooms - \underset{\small (0.00590)}{0.0525}\,stratio \\ & n = 506,\quad R^2 = 0.584 \end{aligned}

H_0: \beta_{\log(nox)} = -1 vs. H_1: \beta_{\log(nox)} \neq -1: \quad t = \dfrac{-0.954 - (-1)}{0.117} \approx 0.39 < 1.96\; → fail to reject H_0.

A common mistake

The t value printed by R always tests H_0: \beta_j = 0. For any other a_j you must compute t yourself.

p-values

Instead of fixing \alpha in advance, ask: what is the smallest significance level at which H_0 would be rejected?

\text{two-sided: } p = P\big(|T| > |t|\big), \qquad T \sim t_{n-k-1}

  • Small p-value = strong evidence against H_0. Reject H_0 at level \alpha iff p < \alpha.
  • R reports p-values for two-sided tests of H_0: \beta_j = 0. For a one-sided test in the direction of the estimate, halve it.
  • The t explorer shows the p-value as the orange tail area beyond t.

Check: what a p-value is (and is not)

A two-sided test gives p = 0.03. Which statement is correct?

A) There is a 3% probability that H_0 is true

B) If H_0 were true, a |t| at least this large would occur in only 3% of samples

C) We reject H_0 at the 1% level

The p-value is computed assuming H_0 is true. It is not the probability that H_0 is true. With p = 0.03 we reject at 5% and 10%, but not at 1%.

Statistical vs. economic significance

  • Statistical significance depends on the t statistic, that is, on the size of the estimate relative to its se.
  • Economic (practical) significance depends on the size of the estimate itself.
  • In large samples, tiny effects can be statistically significant, so smaller \alpha (1%) is appropriate.

Guidelines

  1. Check statistical significance. If significant, discuss the magnitude.
  2. If not significant, check whether the effect is large and the p-value moderate (e.g., 0.10–0.20).
  3. “Wrong” signs with small t can be ignored. A significant wrong sign signals a problem with the model or the data.

Large standard errors

Standard errors shrink roughly like 1/\sqrt{n}. High multicollinearity inflates them. Often the only remedy is more data.

Confidence intervals

The same information as a test, reported as a range of plausible values.

Constructing a confidence interval

Since (\hat\beta_j - \beta_j)/\text{se}(\hat\beta_j) \sim t_{n-k-1}, a 100(1-\alpha)\% confidence interval is

\hat\beta_j \pm c \cdot \text{se}(\hat\beta_j), \qquad c = \text{the } (1-\tfrac{\alpha}{2}) \text{ quantile of } t_{n-k-1}

Three ingredients: the estimate, its standard error and the critical value.

  • For df = 25 and 95%: c = 2.06. For df > 50, \;\hat\beta_j \pm 2\,\text{se}(\hat\beta_j) is a good approximation.

The 95% CI for \beta_{exper} is 0.00412 \pm 1.965 \times 0.00172. What is its lower bound? (answer with 5 decimals)

0.00412 - 1.965\times 0.00172 = 0.00412 - 0.00338 = 0.00074, so the CI is [0.00074,\; 0.00750]. It excludes 0, which matches the two-sided test: p = 0.017 < 0.05.

Confidence intervals and two-sided tests

H_0: \beta_j = a_j is rejected at level \alpha against H_1: \beta_j \neq a_j if and only if a_j lies outside the 100(1-\alpha)\% confidence interval.

Example: a hedonic price model

A hedonic model relates a price to the characteristics of the good (size, rooms, location, …).

data("hprice1")
hed <- lm(log(price) ~ log(sqrft) + bdrms, data = hprice1)
round(cbind(coef(hed), confint(hed)), 3)
#>                     2.5 % 97.5 %
#> (Intercept) -0.623 -2.010  0.764
#> log(sqrft)   0.808  0.612  1.004
#> bdrms        0.038 -0.022  0.098
  • Elasticity of price with respect to size: 0.81, 95% CI [0.61, 1.00]. It excludes 0 (significant), but it includes 1: we cannot reject a unit elasticity.
  • One more bedroom, holding size fixed: about +3.8%, but the CI [−2.2%, 9.8%] contains 0.

Reporting regression results

  • Always report the estimated coefficients and interpret the key ones, taking functional form and units into account.
  • Report standard errors (in parentheses) rather than only t statistics: readers can then test other values and build CIs.
  • Always report R^2 and n. Consider also the SSR and \hat\sigma.

\begin{aligned} \widehat{\log(wage)} &= \underset{\small (0.104)}{0.284} + \underset{\small (0.00733)}{0.0920}\,educ + \underset{\small (0.00172)}{0.00412}\,exper + \underset{\small (0.00309)}{0.0221}\,tenure \\ & n = 526,\quad R^2 = 0.316 \end{aligned}

R toolkit for this topic

res <- lm(log(wage) ~ educ + exper + tenure, data = wage1)
summary(res)                       # t values and two-sided p-values for H0: beta = 0

qt(0.975, df = 522)                # two-sided 5% critical value
qt(0.95,  df = 522)                # one-sided 5% critical value

# H0: beta_exper = 0 vs H1: beta_exper > 0 (one-sided p-value)
tstat <- coef(summary(res))["exper", "t value"]
pt(tstat, df = 522, lower.tail = FALSE)

# H0: beta = a: compute t yourself
b <- coef(res)["educ"]; se <- coef(summary(res))["educ", "Std. Error"]
(b - 0.10) / se

confint(res, level = 0.95)          # confidence intervals

Key takeaways

  1. Under the CLM assumptions (MLR.1–6), (\hat\beta_j - \beta_j)/\text{se}(\hat\beta_j) \sim t_{n-k-1}.
  2. t = (\hat\beta_j - a_j)/\text{se}(\hat\beta_j): the distance from a_j in standard errors.
  3. The alternative decides the rejection region: right, left or two-sided.
  4. p-value: the smallest \alpha at which H_0 is rejected. It is not P(H_0 \text{ true}).
  5. CI: \hat\beta_j \pm c\cdot\text{se}(\hat\beta_j). It contains exactly the values not rejected by a two-sided test.
  6. Statistical significance ≠ economic significance.
