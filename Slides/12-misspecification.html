Previously

Heteroskedasticity broke MLR.5 but left the estimates unbiased. Today we attack MLR.4.

Warm-up: which problem is the most serious?

Which does the most damage to OLS: (i) heteroskedasticity, (ii) omitting a relevant variable or using the wrong functional form, or (iii) measurement error in an explanatory variable?

A) (i) is the worst: heteroskedasticity makes OLS biased

B) (i), (ii) and (iii) are equally bad: each one violates a Gauss–Markov assumption

C) (ii) and (iii) are worse: they violate MLR.4 and make OLS biased and inconsistent, while (i) only distorts the standard errors

Heteroskedasticity affects only inference, and robust standard errors repair it. Anything that puts something correlated with x into the error term, such as an omitted variable, a wrong functional form or measurement error in x, violates MLR.4 and no amount of data can fix it.

Functional form

When the model is wrong in shape rather than in variables: detecting it with RESET.

What counts as misspecification?

A model is misspecified in functional form when it does not capture the relationship between y and the observed regressors. Examples:

  • fitting a level-level model when a log model is correct,
  • leaving out a quadratic term that belongs in the model,
  • leaving out an interaction such as female\cdot educ.

This is a special kind of omitted variable problem: the omitted variable is a function of the included regressors, so it is correlated with them and MLR.4 fails.

Simple remedies first

Use F tests for joint significance of squares and interactions, and try logs for strictly positive variables. Both usually solve the problem.

Ramsey’s RESET test: the idea

If the model is correctly specified, then no nonlinear function of the regressors should help explain y once the linear terms are in.

We could add every square and cross product, but that costs many degrees of freedom. RESET uses a shortcut. The fitted value

\hat y_i = \hat\beta_0 + \hat\beta_1 x_{i1} + \dots + \hat\beta_k x_{ik}

is a single index that combines all the regressors. Therefore

\hat y_i^2 = \big(\hat\beta_0 + \hat\beta_1x_{i1} + \dots\big)^2 = \dots + \hat\beta_1^2x_{i1}^2 + 2\hat\beta_1\hat\beta_2x_{i1}x_{i2} + \dots

already contains all the squares and cross products of the x_j, in one variable. Adding \hat y^2 and \hat y^3 therefore tests for neglected nonlinearity using only 2 degrees of freedom.

RESET step by step

Step 1 — estimate the original model and save the fitted values

\hat y_i = \hat\beta_0 + \hat\beta_1x_{i1} + \dots + \hat\beta_kx_{ik}, \qquad \text{SSR}_r = \textstyle\sum_i \hat u_i^2

Step 2 — re-estimate with \hat y^2 and \hat y^3 added as two new regressors

y = \beta_0 + \beta_1x_1 + \dots + \beta_kx_k + \textcolor{#d9622b}{\gamma_1\hat y^2} + \textcolor{#c0392b}{\gamma_2\hat y^3} + error, \qquad \text{SSR}_{ur}

Step 3 — test the two added terms jointly with an F test

The original model is the restricted model: it is what we get by setting \textcolor{#d9622b}{\gamma_1} = \textcolor{#c0392b}{\gamma_2} = 0.

RESET: hypotheses and the test statistic

H_0: \textcolor{#d9622b}{\gamma_1} = \textcolor{#c0392b}{\gamma_2} = 0 \qquad\text{(the functional form is correct)}

H_1: \textcolor{#d9622b}{\gamma_1} \neq 0 \;\text{ or }\; \textcolor{#c0392b}{\gamma_2} \neq 0 \qquad\text{(neglected nonlinearity: the model is misspecified)}

With q = 2 restrictions and k+2 regressors in the unrestricted model:

F = \frac{(\text{SSR}_r - \text{SSR}_{ur})/2}{\text{SSR}_{ur}/(n-k-3)} \;=\; \frac{(R^2_{ur} - R^2_{r})/2}{(1-R^2_{ur})/(n-k-3)} \;\stackrel{H_0}{\sim}\; F_{2,\,n-k-3}

A large F (small p-value) is evidence against the functional form. Note H_1 does not say which form is right.

Interactive: RESET on house prices

Walk through the three steps with the segmented control. Step 1: y against yhat, the 45-degree line shows what the model predicts. Step 2: the residuals still curve with yhat, so yhat^2 and yhat^3 pick something up. Step 3: the F statistic falls in the rejection region for the level-level model but not for the log-log model.

RESET in R

h1 <- lm(price ~ lotsize + sqrft + bdrms, data = hprice1)
resettest(h1, power = 2:3, type = "fitted")
#> 
#>  RESET test
#> 
#> data:  h1
#> RESET = 4.6682, df1 = 2, df2 = 82, p-value = 0.01202
h2 <- lm(lprice ~ llotsize + lsqrft + bdrms, data = hprice1)
resettest(h2, power = 2:3, type = "fitted")
#> 
#>  RESET test
#> 
#> data:  h2
#> RESET = 2.565, df1 = 2, df2 = 82, p-value = 0.08308

The level-level model is rejected at 5% (p = 0.012); the log-log model is not (p = 0.083). We prefer the log-log specification.

What RESET can and cannot do

Can

  • detect neglected nonlinearities in the included regressors
  • work with any k, using only 2 degrees of freedom

Cannot

  • tell you how to fix the model
  • detect an omitted variable that enters linearly
  • substitute for a test of heteroskedasticity

Non-nested models, e.g. y = \beta_0+\beta_1x_1+\beta_2x_2+u vs. y = \beta_0+\beta_1\log x_1+\beta_2\log x_2+u, cannot be compared with an F test. Options: the Mizon–Richard approach (nest both in a larger model) or the Davidson–MacKinnon test (add the fitted values of one model to the other). Both can reject both models, or neither.

Proxy variables

Putting an imperfect stand-in for an unobserved factor into the regression.

Using a proxy for something unobserved

\log(wage) = \beta_0 + \beta_1 educ + \beta_2 exper + \beta_3\,\underbrace{abil}_{\text{unobserved}} + u

Omitting ability biases \hat\beta_1 upward. A proxy $abil^* $ (e.g. an IQ score) can help if

  1. it is correlated with ability: \;abil = \delta_0 + \delta_3\,abil^* + v_3 with \delta_3 \neq 0,
  2. once the proxy is included, the unobservable is no longer correlated with the regressors: E(abil \mid educ, exper, abil^*) = E(abil\mid abil^*)

Then the plug-in solution (just add the proxy to the regression) gives consistent estimates of \beta_1 and \beta_2.

Example: IQ as a proxy for ability (wage2)

p0 <- lm(lwage ~ educ + exper + tenure + married + south + urban + black, data = wage2)
p1 <- update(p0, . ~ . + IQ)
round(cbind(without_IQ = coef(p0), with_IQ = coef(p1)[names(coef(p0))]), 4)
#>             without_IQ with_IQ
#> (Intercept)     5.3955  5.1764
#> educ            0.0654  0.0544
#> exper           0.0140  0.0141
#> tenure          0.0117  0.0114
#> married         0.1994  0.1998
#> south          -0.0909 -0.0802
#> urban           0.1839  0.1819
#> black          -0.1883 -0.1431
  • The return to education falls from 6.5% to 5.4% once IQ is controlled for: part of what looked like a return to schooling was ability.
  • The coefficient on black also shrinks in absolute value (from -0.188 to -0.143).
  • IQ itself: \hat\beta_{IQ} = 0.0036 (t = 3.6), i.e. 10 more IQ points are associated with 3.6% higher wages.

A lagged dependent variable as a proxy

When we cannot even name the omitted factor, a lagged value of y can stand in for it. City crime rates in 1987 (crime2, 46 cities):

\log(crmrte_{87}) = \beta_0 + \beta_1 unem_{87} + \beta_2\log(lawexpc_{87}) + \beta_3\log(crmrte_{82}) + u

Cities differ in ways we never observe: poverty, the age structure, policing culture. All of these already showed up in the 1982 crime rate, so \log(crmrte_{82}) proxies for them.

c1 <- lm(lcrmrte ~ unem + llawexpc, data = crime2, subset = year == 87)
c2 <- update(c1, . ~ . + lcrmrt_1)

The two estimated equations

Without the proxy

\begin{aligned} \widehat{\log(crmrte_{87})} &= \underset{\small (1.25)}{3.34} - \underset{\small (0.0323)}{0.0290}\,unem + \underset{\small (0.173)}{0.203}\,\log(lawexpc) \end{aligned}

With the lagged crime rate as a proxy

\begin{aligned} \widehat{\log(crmrte_{87})} &= \underset{\small (0.821)}{0.0765} + \underset{\small (0.0195)}{0.00862}\,unem - \underset{\small (0.109)}{0.140}\,\log(lawexpc) \\ & + \underset{\small (0.132)}{1.19}\,\log(crmrte82) \end{aligned}

  • Without the lag, unemployment appears to lower crime, which is hard to believe.
  • With the proxy the sign flips to positive (still insignificant), and R^2 rises from 0.06 to 0.68.
  • The lag is here only to absorb unobservables, not as a causal effect of past crime.

Data problems

Data problems: what can go wrong

So far the model was the problem. Now the data are:

1. Measurement error

We observe an imperfect version of a variable. Consequences differ completely for y and for x — the next three slides.

2. Missing data

Observations with a missing value are dropped. Harmless or not, depending on why they are missing.

3. Nonrandom samples

The sample was selected on the regressors (harmless) or on the dependent variable (biased).

4. Outliers and influential observations

A single observation moves the estimates because OLS minimizes squared residuals.

Measurement error in the dependent variable

Let y be the true variable and y^* the one we observe (reported savings, reported hours). The measurement error is e_0 = y^* - y, and the model we care about is y = \beta_0 + \beta_1x_1 + \dots + \beta_kx_k + u. Substituting y = y^* - e_0:

y^* = \beta_0 + \beta_1x_1 + \dots + \beta_kx_k + \underbrace{(u + e_0)}_{\text{new error}}

  • If E(e_0) = 0 and e_0 is uncorrelated with the regressors, all Gauss–Markov assumptions still hold: OLS on the observed y^* is unbiased and consistent.
  • The only cost is precision: \text{Var}(u + e_0) = \sigma_u^2 + \sigma_{e_0}^2 > \sigma_u^2, so standard errors are larger.
  • If instead e_0 is correlated with an x_j (e.g. the highly educated under-report income), MLR.4 fails and OLS is biased.

Measurement error in an explanatory variable

Now x_1 is measured with error: we observe x_1^* = x_1 + e_1 and run the regression with x_1^*. Everything depends on what e_1 is uncorrelated with.

Case 1: \text{Cov}(x_1^*, e_1) = 0

The error is unrelated to the measure we actually use. Then x_1^* is uncorrelated with the composite error and OLS is consistent; only \sigma^2 and the standard errors grow.

Case 2: \text{Cov}(x_1, e_1) = 0 (CEV)

The classical errors-in-variables assumption: the error is unrelated to the true value. This is the usual case, and now OLS is inconsistent.

The two cases cannot both hold (unless \sigma_{e_1}^2 = 0): under CEV, \text{Cov}(x_1^*, e_1) = \text{Cov}(x_1 + e_1, e_1) = \sigma_{e_1}^2 \neq 0.

Where attenuation bias comes from

Write the true model in terms of the variable we observe, x_1 = x_1^* - e_1:

y = \beta_0 + \beta_1x_1 + u = \beta_0 + \beta_1x_1^* + \underbrace{(u - \beta_1 e_1)}_{\text{new error}}

The regressor and the error now move together, and under CEV the covariance is

\text{Cov}(x_1^*,\, u - \beta_1e_1) = -\beta_1\text{Cov}(x_1 + e_1,\, e_1) = -\beta_1\sigma_{e_1}^2

\text{plim}\,\hat\beta_1 = \beta_1 + \frac{-\beta_1\sigma_{e_1}^2}{\sigma_{x_1}^2 + \sigma_{e_1}^2} = \beta_1\,\underbrace{\frac{\sigma_{x_1}^2}{\sigma_{x_1}^2+\sigma_{e_1}^2}}_{\text{between 0 and 1}}

The multiplying factor is always less than one: the estimate shrinks toward zero. This is attenuation bias, and a larger sample does not remove it.

Interactive: attenuation bias

With sigma_e = 0 the OLS slope is 1. Increase it: the cloud spreads horizontally and the fitted line flattens, exactly following the plim formula. At sigma_e = 1 the estimate is halved. Ask students what this implies for survey data on income or hours worked.

Missing data and nonrandom samples

Missing data

  • R drops incomplete observations, so n falls and the estimates are less precise.
  • If data are missing at random, no bias.
  • If they are missing systematically (e.g. low-education respondents skip the education question), OLS can be biased.

Nonrandom sampling

  • Exogenous selection, based on the regressors (e.g. only people over 35), is harmless.
  • Endogenous selection, based on the dependent variable (e.g. only households with wealth below $250,000), violates MLR.2 and biases OLS.

Example

If IQ scores are easier to obtain for people with high IQ, the sample over-represents them and the estimates are biased.

Outliers and influential observations

An observation is influential if dropping it changes the estimates by a lot. OLS is sensitive because it minimizes squared residuals.

Click the red dot (sales of $39.7 billion, about twice the next largest firm): the coefficient on sales goes from 0.00005 (t = 1.2) to 0.00019 (t = 2.2). Then switch to the log-log model and drop the same firm: the elasticity hardly moves, 1.084 vs 1.088. Logs shrink the range of the data, so they are much less sensitive.

What to do about outliers

r_all  <- lm(rdintens ~ sales + profmarg, data = rdchem)
r_drop <- lm(rdintens ~ sales + profmarg, data = rdchem[-which.max(rdchem$sales), ])
round(cbind(all = coef(r_all), without_largest = coef(r_drop)), 5)
#>                 all without_largest
#> (Intercept) 2.62526         2.29685
#> sales       0.00005         0.00019
#> profmarg    0.04462         0.04784
  1. First check whether it is a data entry error (a misplaced decimal point, an extra zero).
  2. If it is a genuine feature of the distribution, do not delete it silently.
  3. Report the results with and without the observation.
  4. Consider a log transformation, which narrows the range and often removes the problem.

Outliers can be informative

An extreme value also adds variation in x, which lowers the standard errors. The goal is transparency, not removal.

Check your understanding

A survey measures household income with error. Income is the explanatory variable. What happens?

A) OLS stays consistent, only the standard errors grow

B) The estimated coefficient on income is biased toward zero (attenuation), and a larger sample does not help

C) The intercept is biased, but the slope is fine

Under the classical errors-in-variables assumption the mismeasured regressor is correlated with the composite error, so OLS is inconsistent. Answer (A) describes measurement error in the dependent variable.

Key takeaways

  1. Wrong functional form is an omitted variable problem: use logs, quadratics, interactions and the RESET test.
  2. A proxy variable can cut omitted variable bias: with IQ in the model, the return to education falls from 6.5% to 5.4%.
  3. Measurement error in y: harmless on average. In x: attenuation bias and inconsistency.
  4. Missing data and nonrandom samples are harmless only if unrelated to y given the regressors.
  5. Outliers: investigate, report with and without, and consider logs.
